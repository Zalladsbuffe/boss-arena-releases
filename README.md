# Boss Arena

Ett 3D-bossarenaspel i webbläsaren.

## Ladda ner (Windows)

**[⬇ Ladda ner BossArena-Setup.exe](https://github.com/Zalladsbuffe/boss-arena-releases/raw/main/BossArena-Setup.exe)**

1. Kör filen. Windows kan visa "Windows skyddade datorn" eftersom appen inte är signerad. Klicka då på **Mer info** och sedan **Kör ändå**.
2. Appen installeras och startar. En genväg hamnar på skrivbordet.
3. Nya versioner laddas ner automatiskt när appen startar (och kollas var 20:e minut medan du spelar).

**Tips:** `F11` växlar helskärm. Grafiken ställer du in i pausmenyn (`Esc`).

## Filer

- `game.html` – själva spelet (en enda fil, går också att öppna direkt i Chrome/Edge).
- `version.json` – vilken version som är den senaste (appen läser den).
- `BossArena-Setup.exe` – installationsfilen för Windows.
